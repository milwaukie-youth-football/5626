---
title: Mirror Passing
---

Skills drill for max reps. Set up two mirrored formations at once, either [[offense/formations/maroon|Maroon]] or [[offense/formations/gold|Gold]], with the running back(s) and WRs to each side of a shared QB/center. Run the same play to either side back-to-back so both sides get reps without resetting between calls.

- Pick one formation (Maroon or Gold) and mirror it left and right.
- RB(s) and WRs set on each side; QB works both sides in turn.
- Call the play, run it right, reset, run it left: repeat to build reps quickly.
